# TSC-1_A Project

## Overview

The TSC-1_A project

## Directory Structure

- **A_Adapter**: This directory contains the main board project for the adapter. It includes all relevant source files and configurations needed to build and deploy the adapter's firmware.

- **A_board**: Similar to `A_Adapter`, this directory is for the main board project itself. It encompasses all necessary files for the development of the main board’s firmware.

- **ext_lib**: The `ext_lib` directory houses external libraries that are referenced by the main projects. These libraries provide additional functionality that is utilized across the TSC-1_A project.

- **Functional_test**: This directory contains various projects dedicated to functional testing. These projects are designed to ensure that all components of the system are working as expected through a series of automated tests.

- **LAB**: The `LAB` directory is where feasibility studies and experimental setups are conducted. It includes preliminary tests, proofs of concept, and other experimental work.

### Running Experiments in the LAB

- To perform feasibility tests or run experiments, navigate to the `LAB` directory and follow the specific instructions provided in the respective subdirectories.
