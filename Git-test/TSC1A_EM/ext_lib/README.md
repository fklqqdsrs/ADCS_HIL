# ext_lib

## Overview

The `ext_lib` directory contains external libraries that are used across the TSC-1_A project. These libraries provide additional functionalities and are critical for the operation of both the `A_Adapter` and `A_board` projects.

## Structure

- **lib1/**: Description of Library 1.
- **lib2/**: Description of Library 2.

Each subdirectory contains the source code, binaries, and documentation for the respective libraries.

## Adding New Libraries

To add a new external library:

1. Create a new directory within `ext_lib/`.
2. Add the library files (source, binaries, headers).
